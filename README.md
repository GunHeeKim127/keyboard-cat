# Keyboard Cat 1.3.5

키보드 입력 횟수에 반응하는 Windows/macOS 데스크톱 반려동물입니다. 기존 고양이와 치와와·진돗개·리트리버·시바견·허스키 중 하나를 리모컨에서 마우스로 선택합니다. 현재 수정 빌드 표시는 **강아지 보행 수정 2**입니다. 강아지 기능을 별도 버전으로 구분하도록 사용자 요청에 따라 1.3.5로 올렸습니다.

## 설치와 실행

- Windows: `release/Keyboard Cat 1.3.5.exe`는 휴대용, `release/Keyboard Cat Setup 1.3.5.exe`는 설치형입니다. `Start Keyboard Cat.cmd`는 로컬 빌드와 Electron이 있으면 수정된 개발본을 우선 실행하며, 없으면 `release/win-unpacked/Keyboard Cat.exe`를 실행합니다.
- macOS: Apple Silicon은 `Keyboard-Cat-1.3.5-mac-arm64.dmg`, Intel은 `Keyboard-Cat-1.3.5-mac-x64.dmg`입니다. 앱을 완전히 종료하고 DMG의 앱을 Applications에 교체한 뒤 Finder에서 실행합니다. Node.js/Xcode는 설치 파일 사용자에게 필요하지 않습니다.
- 리모컨 상단의 v1.3.5와 강아지 5종 · 마우스 선택 표시를 확인하세요. 새 설치 파일 검증 후 이전 로컬 설치 파일을 정리하며 사용자 설정과 Git 이력은 보존합니다.
- Windows 코드는 서명하지 않았고 Mac 테스트 빌드는 임시 서명(ad hoc)입니다. 유료 Developer ID 서명·Apple 공증·새 GitHub Release 게시를 자동 수행하지 않습니다. Mac 권한·설치 안내는 [MACOS.md](MACOS.md), 별도 서명 배포 구성 설명은 [MACOS-DISTRIBUTION.md](MACOS-DISTRIBUTION.md)를 참고하세요.

1.3.5 Mac 설치 파일: [Apple Silicon DMG](https://github.com/GunHeeKim127/keyboard-cat/actions/runs/39386230426/artifacts/12247557103) · [Intel DMG](https://github.com/GunHeeKim127/keyboard-cat/actions/runs/39386230426/artifacts/12248010710) · [빌드/검증 기록](https://github.com/GunHeeKim127/keyboard-cat/actions/runs/39386230426). Actions 산출물 보관 기간은 14일입니다.

프로젝트는 OneDrive 동기화 경로 밖의 일반 로컬 폴더(예: `C:\Users\<사용자>\projects\keyboard-cat`)에서 작업합니다. 로컬 이전 후 소스·보고서·Git 이력의 복사 무결성, 의존성 재설치, 빌드·테스트와 실제 앱 실행을 검증했습니다. 새 폴더의 release에는 1.3.5 설치 파일 두 개와 현재 체크섬만 두며 이전 설치 파일은 보존하지 않습니다. 앱 사용자 설정은 유지합니다.

## 1.3.5 강아지 모션 수정

보행 수정 2: 다섯 견종의 걷기 이미지를 다시 제작해 뒷다리가 굽은 채 끌려 보이는 자세를 줄이고, 좌우 뒷발이 구분되도록 조정했습니다. 8프레임과 기존 느린 모션 설정은 유지합니다. 이전 걷기 원본은 보존하며 현재 빌드는 `*-walk-v2-sheet.png`를 사용합니다.

- 원본 시트의 칸 경계를 넘은 포즈를 통째로 추출해 아래쪽에 옆 포즈가 반복되던 현상을 수정했습니다.
- 다섯 견종의 걷기를 8프레임으로 교체하고 발의 기준선과 크기를 맞췄습니다.
- 짧은 모션은 프레임마다 대기 0.5초, 점프 0.4초, 대시 0.35초, 놀이 0.45초, 수면 1.2초, 들기 0.65초, 사다리 0.35초 이상 유지합니다. 사용자가 낮춘 FPS도 존중합니다.
- 점프→낙하→착지는 총 1.7초, 사다리 오르내리기→착지는 총 3.3초입니다. 고양이의 기존 재생 속도와 리모컨 스위치는 유지합니다.
- 원래 프로젝트 폴더를 복구해 현재 수정은 그 위치에서 진행합니다. 로컬 복사본은 보존합니다.

## 반려동물과 견종 선택

리모컨의 고양이/강아지 버튼을 클릭합니다. 강아지를 선택하면 견종 메뉴가 나타나며 마지막으로 선택한 견종은 고양이로 바꾸거나 앱을 다시 실행해도 저장됩니다. 화질 프리셋을 바꿔도 반려동물·견종·이름·다중 모니터 선택은 유지합니다. 트레이에도 직접 선택 메뉴가 있습니다.

**Tab을 포함한 키보드 전환 단축키는 없습니다.** 다른 프로그램에서 Tab을 눌러도 반려동물 선택은 바뀌지 않습니다. 입력 감지 권한이 없거나 일시정지 상태여도 리모컨에서 직접 선택할 수 있습니다.

| 견종 | 이미지와 모션의 특징 |
| --- | --- |
| 치와와 | 큰 귀와 작은 체구, 경쾌한 발걸음과 통통 뛰는 자세 |
| 진돗개 | 흰 털과 쫑긋한 귀, 또렷한 자세와 날렵한 달리기 |
| 리트리버 | 황금색 털과 늘어진 귀, 풍성한 꼬리와 반가운 앞발 동작 |
| 시바견 | 주황색·크림색 털과 말린 꼬리, 장난스러운 웃음과 놀이 자세 |
| 허스키 | 회색·흰색 얼굴 무늬와 파란 눈, 힘찬 달리기와 장난스러운 도약 |

다섯 견종마다 기존 24개 포즈와 새 8프레임 걷기를 사용합니다. 대기·걷기·점프·낙하·착지·대시·놀이(ATTACK)·수면·들기·사다리에 연결하며 사다리 내려오기는 해당 프레임을 역순으로 재생합니다. 견종 특징은 귀여운 시각적 해석입니다. 기존 고양이 원본·아틀라스·들기 이미지는 보존합니다.

## 리모컨 기능과 켜기·끄기

기존의 **자동 이동, 콤보 특수 효과, 대기 애니메이션, 수면 애니메이션, 콤보 숫자 표시, 마우스로 집어 들기, 다중 모니터 이동** 일곱 스위치를 모두 유지합니다. 고양이와 강아지에 동일하게 적용됩니다. 크기·FPS·위치 초기화·입력 다시 연결·일시정지·리모컨 숨기기·앱 종료도 유지합니다.

| 품질 | 크기 | 재생 속도 | 자동 이동 | 특수 효과 | 대기 반복 | 수면 반복 |
| --- | --- | --- | --- | --- | --- | --- |
| 저 · 기본 | 75% | 5 FPS | 끔 | 끔 | 끔 | 끔 |
| 중 | 100% | 8 FPS | 끔 | 켬 | 끔 | 켬 |
| 고 | 130% | 12 FPS | 켬 | 켬 | 켬 | 켬 |

- 기능은 개별 조정할 수 있으며 성능 관련 값을 바꾸면 사용자 설정으로 표시됩니다. 수면 반복은 별도로 켤 수 있고 2.5 FPS로 재생합니다. 꺼도 정지된 수면 자세는 표시합니다.
- 다중 모니터 이동을 끄면 주 모니터로 제한합니다. 다시 켜면 다른 모니터로 이동할 수 있으며 여러 마리로 복제하는 기능은 아닙니다.
- 마우스로 집어 들기를 켜면 반려동물 영역만 클릭을 받고 주변 투명 영역은 통과합니다. 끄면 클릭을 통과시킵니다. 위치 조정 모드에서는 드래그로 이동합니다.
- 아바타 이름은 최대 20자이며 마우스를 올리면 하단에 나타납니다. 현재 이름 설정은 고양이와 강아지가 공유합니다.
- 리모컨을 숨겨도 반려동물은 계속 표시됩니다. 트레이 아이콘을 더블클릭하거나 실행 파일을 다시 실행하면 리모컨을 엽니다.
- 일시정지는 입력 보조 프로그램과 재시도를 중지하고 콤보를 초기화합니다.

## 입력과 콤보

1.5초 미만 간격으로 키를 누르면 콤보가 이어집니다. 콤보 특수 효과를 켰을 때 아래 배수마다 반복합니다. 저품질 기본값은 효과 끔이므로 필요하면 리모컨에서 켜세요.

| 콤보 | 모션 |
| --- | --- |
| 10의 배수 | 점프 → 낙하 → 착지 |
| 20의 배수 | 사다리 오르기 → 내려오기 → 착지 |
| 30의 배수 | 대시 |
| 50의 배수 | 고양이 공격 / 강아지의 놀이·앞발 모션 |

겹치면 50 공격/놀이 → 30 대시 → 20 사다리 → 10 점프 순서입니다. 40은 사다리, 60은 대시, 100·150은 공격/놀이입니다. 사다리는 제자리 애니메이션이며 창을 위아래로 옮기지 않습니다. 입력이 없으면 약 4초 후 걷기, 30초 후 수면으로 전환합니다. 점프·대시를 Space/Shift에 연결하지 않으며 키 종류와 관계없이 기존 횟수 방식으로 반응합니다.

## 개인정보와 보안

Windows는 전역 키보드 훅 대신 Raw Input 알림을 받고, macOS는 읽기 전용 CoreGraphics 이벤트 탭을 사용합니다. 최종본은 키 코드·문자·키 이름·창 제목을 읽거나 기록하지 않고 누름 횟수만 처리합니다. 다른 앱 입력을 억제하지 않습니다. 입력 횟수와 내용은 파일에 저장하거나 외부로 전송하지 않습니다. 저장하는 것은 위치·이름·반려동물·견종과 사용자 옵션입니다.

설정은 Windows의 `%APPDATA%/keyboard-cat/settings.json`, Mac의 `~/Library/Application Support/keyboard-cat/settings.json`에 있습니다. 리모컨의 입력 진단은 요청할 때만 실행 위치, 고정 오류 코드, 흔한 위치의 앱 복사본과 설정·캐시 경로를 읽기 전용으로 확인합니다. 진단 복사에는 경로의 사용자 이름이 포함될 수 있으니 공유 전 확인하세요. 권한 DB·다른 앱·사용자 설정은 자동 삭제하거나 초기화하지 않습니다.

Electron contextIsolation·sandbox·Node 접근 차단, IPC 창/최상위 프레임/문서/자료형 검증, 로컬 리소스 허용 목록, CSP, 웹 권한·다운로드·탐색 차단을 유지합니다. 설정 파일은 최대 64KiB만 읽고 이름은 HTML이 아닌 텍스트로 표시합니다. 견종·반려동물 값도 허용 목록으로 검증합니다. 2026-10-20 npm 감사에서 9개 취약점을 의존성 수정 후 0개로 줄였으며 이번 기능 추가에는 의존성 변경이 없습니다. npm에 앱을 게시하지 않았습니다.

## macOS 입력 권한

시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링에서 현재 설치본을 허용합니다. 권한 부족이나 이벤트 탭 오류 후에는 5초 간격으로 보조 프로그램을 다시 연결하며, 자동 재연결에서 권한 요청 팝업을 반복하지 않습니다. 준비 신호가 와야 준비 완료로 표시합니다. macOS가 요구하면 앱을 완전히 종료하고 다시 실행하세요.

앱 재설치가 macOS의 기존 권한 기록까지 지우는 것은 아닙니다. 입력 진단으로 실행 위치와 실패 상태를 먼저 확인하고, 앱별 권한 기록 초기화 절차는 [MACOS.md](MACOS.md)를 참고하세요. 실제 사용자 Mac에서 보고한 권한 거부 원인은 아직 확정되지 않았으며 빌드 성공과 실제 물리 입력 성공을 구분합니다.

## 개발과 검증

Node.js 22.12 이상(24 권장), npm, Windows 기본 .NET Framework 4.x 또는 Mac Xcode Command Line Tools가 필요합니다. 현재 검증은 Node 24를 사용합니다.

```sh
npm ci
npm run build
npm test
npm start
npm run dist:win
# Mac에서:
npm run dist:mac
```

`npm run dev`는 빌드 후 실행하며 `npm run sprites`는 고양이 프레임과 강아지 아틀라스를 다시 만듭니다. 새 이미지 생성은 빌드에 포함되지 않으며 저장된 원본 PNG만 사용합니다. 설치 파일 생성은 --publish never이며 Git 커밋·푸시를 자동 수행하지 않습니다.

```sh
npx electron . --smoke-test
node scripts/check-native.cjs
```

현재 모션 수정본의 로컬 빌드·양쪽 TypeScript 검사·58개 테스트, Windows 네이티브 등록과 소스 앱/실제 패키지 실행 검사가 통과했습니다. Windows 휴대용/설치형 EXE 무결성과 검증한 앱 payload의 일치도 확인했습니다. 실제 리모컨에서 5종×11개 상태 로딩·선택 저장·고양이 복귀·기존 일곱 토글 각각의 켜기/끄기, 기존 좌표·집기·IPC/웹 보안도 검사합니다. 스모크 검사는 임시 설정을 쓰며 실제 물리 입력을 켜지 않습니다. 별도 lint 명령은 설정되어 있지 않습니다.

실제 Mac 물리 키 입력과 권한 변경, 실제 다중 모니터 조작과 절전 복귀는 사용자 환경 확인이 필요합니다. 합성 키 입력을 물리 키 입력 검증으로 취급하지 않습니다. 이번 모션 수정 이전 1.3.5에서 Mac 컴파일·55개 테스트·두 아키텍처 helper 검사·DMG/ZIP 생성·번들/서명/압축 무결성 검사와 업로드가 성공했습니다. [모션 수정 이전 1.3.5 Mac 빌드](https://github.com/GunHeeKim127/keyboard-cat/actions/runs/39386230426)의 소스는 e185566입니다. 이번 강아지 모션 수정의 Mac 실행·패키징은 아직 확인하지 않았습니다. 이전 로컬 폴더 검증에서는 빌드·55개 테스트·네이티브 등록·실제 패키지 실행과 두 EXE 무결성 검사가 통과했습니다. 유료 서명·공증·새 Release 게시는 수행하지 않았습니다.

## 소스와 이미지 위치

- `electron/`: 창·IPC·옵션·콤보·좌표·진단·반려동물 허용 목록.
- `src/`: 고양이·강아지 표시와 리모컨 UI.
- `native/`: Windows Raw Input과 Mac 읽기 전용 횟수 감지.
- `scripts/`: 빌드·고양이 프레임 추출·강아지 아틀라스 패킹·패키지 검증.
- `tests/`: 콤보·좌표·옵션·보안·입력 수명·배포와 강아지 리소스 회귀 검사.
- `public/sprites/`: 기존 고양이 아틀라스 9개와 carry.png, 새 dog-<견종>-<상태>-atlas.png 50개. 런타임 파일은 동일한 평면 리소스 허용 목록 안에 있습니다.
- `assets/dogs/`: 새로 생성한 다섯 원본 시트. 내장 imagegen 도구를 사용했으며 프롬프트와 4×6 셀 구성은 [GENERATION.md](assets/dogs/GENERATION.md)에 보관합니다. 별도 유료 API 호출이나 외부 스프라이트 다운로드는 하지 않았습니다.
- `CHANGELOG.md`: 최근 수정 빌드별 상세 변경 기록.

참고: [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window), [Microsoft Raw Input](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input), [Apple 입력 권한 초기화](https://developer.apple.com/documentation/xcode/resetting-access-to-protected-resources-in-macos).
