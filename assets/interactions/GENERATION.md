# 추가 상호작용 이미지 제작

내장 image_gen 도구로 기존 26종의 IDLE 이미지 줄 모음을 참고해 제작했습니다. 기존 PNG를 덮어쓰지 않고 이 폴더에 별도 제작 원본을 저장합니다. 각 행은 catalog.json의 종 순서입니다.

- `*-sheet.png`: 폴더 진입, 닫힌 폴더에서 나오기, 열린 창에서 나오기, 쓰다듬기. 종별 기존 얼굴·털색·깃색·몸 비율을 유지하고 전신 자세를 요청했습니다. 사람 손, 배경, 폴더 그림, 글자를 넣지 않도록 했습니다.
- `gentoo-petted-sheet.png`: 젠투의 쓰다듬기 자세 보정. 노란 눈썹깃이 섞인 후보를 제외하고 흰 머리띠·주황 부리·발을 유지한 네 자세를 별도로 요청했습니다.
- `*-fall-sheet.png`: 네 낙하 자세와 두 착지 자세. 전체 몸이 일관되도록 요청했고 새는 두 발·날개, 펭귄은 두 발·물갈퀴, 포유류는 해당 종의 팔다리·꼬리를 유지합니다.

주요 지시 요약: “참고 줄 모음의 각 동물 외형과 색·얼굴·몸 크기를 그대로 보존한 귀여운 픽셀 전신 자세. 각 모션을 별도 셀로, 투명 배경과 충분한 간격으로 배치. 팔다리 분리·왜곡·이웃 종 특징 혼합·문자·소품·배경 금지.”

생성 결과의 격자 수와 여백이 일정하지 않아 실제 알파 연결 성분으로 전신을 분리하고, 잘린 셀과 이웃 자세의 잔재를 제외했습니다. 일부 잘린 후보 대신 같은 동작의 완전한 자세를 유지하거나 기존 IDLE 자세를 연결 자세로 사용합니다. 프로그램으로 새 신체 부위를 그리거나 실행 중 관절을 따로 움직이지 않습니다. 앱에서는 최종 100×110 전신 PNG만 재생합니다.

낙하와 착지는 전신 연결 성분 6개씩을 행별로 확인합니다. 몸 크기는 기존 IDLE의 보이는 크기를 기준으로 맞추며, 원본 그림과 기존 보행·콤보 이미지는 수정하지 않습니다. 자연스러움의 자동 보장을 뜻하지 않으므로 실제 크기 비교와 로컬 앱 재생을 함께 확인합니다.

## 펭귄 창 바라보기

내장 image_gen으로 기존 펭귄 외모를 참고해 5행 × 8열 투명 시트를 제작했습니다. 지시: 기존 색·눈·부리·머리 무늬와 체형을 유지하고 오른쪽 창 → 고개 기울이기 → 사용자 정면 → 오른쪽 창의 전신 자세를 순서대로 배치. 채택 원본은 `penguin-window-look-sheet.png`, 포장 결과는 WINDOW_LOOK 40개입니다. 각 종의 기존 대기 자세 높이에 맞추고 연결된 전신 그림만 잘라 저장합니다. 오르기 후보들은 검토 중이며 실행파일 자산에 포함하지 않습니다.

## 낮은 펭귄 점프

내장 image_gen을 사용했습니다. 참고는 기존 펭귄 대기 자세이며 지시는 ‘5종 각각 기존 외모·무늬·비율 유지, 8개 전신 자세: 서기 → 웅크리기 → 두 발로 밀기 → 낮은 공중 자세 → 착지 준비 → 두 발 착지 → 균형 잡기 → 서기, 정확히 두 발, 비행·벽·파란 가이드·소품 없이 투명 배경’입니다. 채택 원본 `penguin-hop-sheet.png`, 결과 HOP 40장입니다. 앱 이동 진행률과 8개 그림을 맞추며 준비·착지 중에는 위치를 미끄러뜨리지 않습니다.

수직 오르기 생성 후보는 사용자 피드백에 따라 채택하지 않았습니다. 벽 모션은 기존 전신 보행 그림을 벽 방향에 맞춰 쓰므로 새 동물 외모나 팔다리 조각을 추가하지 않습니다.

## 앵무새 전용 수직 모션

내장 image_gen으로 각 종의 기존 IDLE 그림과 공개 연구의 수직 오르기 자세를 참고했습니다. 연구: https://pmc.ncbi.nlm.nih.gov/articles/PMC9115034/ (직접 대상은 모란앵무). 지시: 기존 외모·깃 무늬·체형 유지, 종별 4×4의 16개 전신 자세, 머리·몸통 세우기, 부리로 지지하며 두 발을 서로 다른 높이로 번갈아 옮기기, 날개 접기, 부리는 발이 아님, 벽·가지·파란 가이드 없이 투명 배경. 유리앵무 후보의 불투명 배경은 내장 이미지 편집으로 제거했습니다. 채택 원본은 `parrot-*-edge-sheet.png`, 실행 결과는 EDGE_CLIMB 80개입니다. 고해상도 제작 원본은 패키지에 포함하지 않습니다.
