# Mac 권한 재연결 수정 2 (2.5.2 기반)

이전 시험판에서 권한을 허용했는데 입력이 연결되지 않는 문제를 확인하기 위한 수정 시험판입니다. 앱 안에 **Mac 권한 재연결 수정 2**가 표시됩니다. 앱 버전은 2.5.2로 유지합니다.

## 받는 파일
- M1 Pro를 포함한 Apple 칩 Mac: **Keyboard-Cat-2.5.2-permission-preview2-arm64.dmg**
- Intel Mac: **Keyboard-Cat-2.5.2-permission-preview2-x64.dmg**
- 자세한 설치·확인 방법: **[한글 설치·확인 안내](https://github.com/GunHeeKim127/keyboard-cat/releases/download/mac-fixed-identity-preview-2/Mac-Permission-Fix2-Guide-KO.md)**
- tar.gz는 자동 검사용 자료입니다. 설치할 때는 DMG를 받으세요.

## 바뀐 부분
- 권한 대기 중인 보조 프로그램이 남아 재연결을 건너뛰던 경로를 수정했습니다.
- 권한 설정에서 리모컨으로 돌아오면 새 보조 프로그램으로 다시 연결합니다.
- OS 요청이 끝없이 대기하면 2분 후 팝업 없이 복구를 시도합니다. 정상 연결되면 복구 예약을 해제하며, 일시정지·종료하면 재시도도 취소합니다.
- 입력 진단에 앱과 보조 프로그램의 공개 서명 식별 정보를 추가했습니다. 버튼을 눌렀을 때만 비동기로 조회합니다.
- 기존 PNG 1,703개와 동작·품종·설정을 보존했습니다. dir 빌드에서 빠졌던 공개 업데이트 설정도 기존 값으로 포함했습니다.

## 설치와 확인
현재 앱 완전 종료 → DMG에서 Applications(응용 프로그램)으로 끌어 넣고 교체 → DMG 추출 → Finder의 응용 프로그램에서 실행합니다. 기존 설정과 캐시는 지우지 마세요.

이전 시험판에서 이미 권한을 허용했다면 먼저 **권한을 바꾸지 않은 상태**에서 일반 메모장에 한글·영문을 입력해 확인하세요. 이전과 동일한 고정 인증서와 앱·보조 프로그램 서명 ID를 유지했습니다.

계속 연결되지 않으면 리모컨에서 입력 진단을 복사해 보내주세요. 새 진단의 실행 위치·연결 진단·앱 서명 식별·입력 보조 프로그램 서명 식별이 필요합니다. 사용자 이름은 가려도 됩니다.

## 검증 범위
두 Mac 환경의 빌드·실행·상호작용 검사와 자동 검사 236개, 최종 고정 서명 파일의 Apple 기본 검증·실행 검사, 해시·코드 보존 검사를 수행했습니다. 공식 npm 취약점 검사에서 현재 고정 의존성의 알려진 취약점은 0건이었습니다.
